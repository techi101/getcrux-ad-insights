Limits, stated plainly

  • Spend confounding. In this dataset impressions were not steered by performance (rank correlation between impressions and CTR is about zero). On Meta, Google and TikTok the delivery algorithm does push spend toward ads it expects to win, so a naive "feature → performance" model is confounded by spend. The fix is the same as above: compare inside the same ad set and time window, and confirm with a holdout.
  • The budget numbers are a simulation that assumes each creative's CTR is fixed. The "calling a winner" chart shows CTRs drift, so real gains would likely be smaller.
  • No image features yet. The creative images are a 115 GB archive; this report uses the performance logs only.
  • Domain: e-commerce display ads, not video ads for US apps. The methods carry over; the exact numbers will not.
